# Karier Kedua — Website (Next.js 14 + TS + Tailwind)
Setup: `npm install` then `npm run dev`.
Content lives in `/data`. Images go in `public/images/{hero,facilitators,clients,gallery,workshops,csr,books}` (e.g. `hero/hero-main.jpg`, `facilitators/<slug>.jpg`, `clients/<slug>.png`, `gallery/gallery-01.jpg`).
Placeholders: `components/Placeholder.tsx`. WhatsApp URL: `lib/utils.ts`.
Dummy assets are SVGs in public/images (regenerate or replace with real photos). Main menu is `mainNav` in data/brand.ts.
